NORDVOW MARKA VARLIKLARI
========================
Bu klasördeki dosyalar siteye public olarak sunulur; doğrudan indirilebilir/paylaşılabilir.

Canlı adresler (nordvow.com):
  /brand/nordvow-mark.svg          256x256 logo monogramı (N), şeffaf köşeli kare
  /brand/nordvow-logo-dark.svg     logo + "Nordvow" (KOYU zemin için, beyaz yazı)
  /brand/nordvow-logo-light.svg    logo + "Nordvow" (AÇIK zemin için, koyu yazı)
  /brand/nordvow-banner.svg        1200x630 tanıtım/sosyal banner (statik SVG)

Sosyal paylaşım (Open Graph) görseli:
  /opengraph-image               Next tarafından dinamik üretilen 1200x630 PNG.
                                 Link paylaşıldığında (WhatsApp, X, LinkedIn, Slack) bu çıkar.

Renk paleti (gradyan): #9d4dff (mor) -> #ff2bd6 (pembe) -> #00e5ff (cyan)
Yazı tipi: Geist / Inter / system-ui

PNG gerekiyorsa:
  SVG'leri tarayıcıda açıp dışa aktarın ya da:
  (ör.) rsvg-convert veya Inkscape ile:  rsvg-convert nordvow-banner.svg -o banner.png
