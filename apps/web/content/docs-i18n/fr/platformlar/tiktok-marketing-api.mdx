## Statut

- La création/gestion de campagnes et l'API Split Test sont disponibles.
- Les limites de débit (QPS) ne peuvent pas être vérifiées à partir de sources officielles <Unverified />. Aucun nombre fixe n'est utilisé ; une limitation adaptative + retrait en cas de 429 est appliquée.
- La durée de l'examen des applications n'est pas garantie <Unverified />.

## Spark Ads

Dans le modèle de liaison de compte Business Center, **tout le monde** ayant accès au compte lié peut l'utiliser comme identifiant publicitaire ; c'est pourquoi un code d'autorisation par publication est ciblé. Les domaines et la durée de validité du code ne peuvent pas être vérifiés à partir de sources officielles <Unverified /> ; la fonctionnalité est derrière un drapeau fermé.

**L'API Spark Ads Recommendation** est destinée à trouver du contenu organique digne d'être boosté (squelette).

## Préparation de l'examen des applications

Site web en direct ; Politique de confidentialité et Conditions d'utilisation visibles et fonctionnelles sans accéder au menu (`/gizlilik`, `/kullanim-kosullari`) ; explication d'utilisation pour chaque permission ; maximum 5 vidéos de démonstration (chacune ≤ 50 MB, flux de bout en bout) ; sandbox à la première soumission ; permissions inutilisées supprimées. Application web au lieu d'application mobile.
