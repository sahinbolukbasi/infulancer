## Chaque actif généré

- Les C2PA Content Credentials sont exportés **intégrés** ; le modèle qui a généré quel actif est enregistré dans le système.
- **Meta :** lors de la création d'une publicité/publication, vérifiez la déclaration « Créé avec l'IA ». Sur les téléchargements avec C2PA, l'étiquette « AI Info » s'applique automatiquement.
- **TikTok :** si la description d'une personne/lieu/événement réaliste est présente, activez l'étiquette AIGC ; s'il s'agit de contenu de marque, activez également la déclaration de contenu commercial.
- S'applique conjointement avec [md. 23/A](/docs/uyum/reklam-aciklamasi-23a).
- Si un persona virtuel/IA est utilisé, une explication IA est fournie séparément (le numéro d'article est contradictoire entre les sources <Unverified />).
- L'EU AI Act md. 50 exige un marquage lisible par machine du contenu synthétique (depuis le 2 août 2026 ; délai jusqu'au 2 décembre 2026 pour les systèmes déjà sur le marché).

<Callout type="yasak">La production avec une copie d'intelligence artificielle d'une personne réelle, donnant l'impression que cette personne utilise ou recommande le produit (**md. 27/12**) est **toujours interdite** — ce n'est pas permis même avec une étiquette. Si le nom/nom d'utilisateur d'un influenceur du système, le clonage de visage/voix ou une référence de portrait reconnaissable est détecté dans le brief, le travail est rejeté.</Callout>

Une fonctionnalité supprimant les métadonnées **n'est pas proposée**. Il n'a pas été testé si les sorties de divination portent C2PA <Unverified /> ; le système ajoute son propre manifeste dans tous les cas.
