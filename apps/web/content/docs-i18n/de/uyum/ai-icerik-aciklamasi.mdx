## Jedes generierte Asset

- C2PA Content Credentials werden **eingebettet** exportiert; welches Modell welches Asset generiert hat, ist im System erfasst.
- **Meta:** Überprüfen Sie beim Erstellen von Anzeigen/Beiträgen die Erklärung „Mit KI erstellt". Bei Uploads mit C2PA wird das Label „AI Info" automatisch angewendet.
- **TikTok:** Wenn realistische Darstellungen von Menschen/Orten/Ereignissen vorhanden sind, aktivieren Sie das AIGC-Label; wenn es sich um Branded Content handelt, aktivieren Sie auch die kommerzielle Inhaltserklärung.
- Wird zusammen mit [md. 23/A](/docs/uyum/reklam-aciklamasi-23a) angewendet.
- Wenn virtuelle/KI-Personas verwendet werden, wird eine separate KI-Erklärung abgegeben (Artikelnummer widerspricht sich in den Quellen <Unverified />).
- EU AI Act md. 50 verlangt maschinenlesbare Kennzeichnung synthetischer Inhalte (seit 2. August 2026; für bereits auf dem Markt befindliche Systeme bis 2. Dezember 2026).

<Callout type="yasak">Die Produktion mit einer KI-Kopie einer echten Person, die den Eindruck erweckt, dass diese Person das Produkt verwendet oder empfiehlt (**md. 27/12**), ist **immer verboten** — auch mit Label nicht zulässig. Wenn in der Briefing der Name/Benutzername eines Influencers im System, Gesichts-/Stimmenklonung oder erkennbare Porträtreferenzen erkannt werden, wird der Auftrag abgelehnt.</Callout>

Eine Funktion, die Metadaten löscht, wird **nicht angeboten**. Es wurde nicht getestet, ob Orakel-Ausgaben C2PA tragen <Unverified />; das System fügt sein eigenes Manifest in jedem Fall hinzu.
