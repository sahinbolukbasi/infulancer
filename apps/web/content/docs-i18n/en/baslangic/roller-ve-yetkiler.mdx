## Roles

| Role | Sees | Does |
|---|---|---|
| Admin (agency) | Everything | Campaign, influencer, brand, finance, compliance, agent and invitation management |
| Brand | Only their own campaigns, inbox, assistants, compliance status | Draft approval/revision, report download, assistant settings, KVKK receipt, İYS records |
| Influencer | Only their own work, payments, accounts | Draft upload, metric entry, shoot request, TikTok connection, influencer invitation |

Brand does not see the fee paid to influencer and agency commission; only sees the total amount paid by the brand.

## Invitation-based membership

- Registration to the platform is only via invitation link (`/kayit?kod=…`).
- Admin generates influencer or brand invitations; influencer can only generate influencer invitations (maximum 5 active invitations, maximum 3 uses per invitation, maximum 30 days).
- The registered person only sees the "Your membership is pending approval" screen until admin approves.
- Upon approval, profile is created automatically. Influencer's payment is locked until their tax status is determined.

## Documentation access

Admin and brand see all pages; influencer only sees the "Influencer guide" section.
