## Audit restriction

Until the application passes TikTok review, posts can only be made via API with `SELF_ONLY` visibility; paid partnership disclosure content cannot be **published** in this mode. Before audit, a maximum of 5 users can post within 24 hours.

→ In practice, TikTok posts are done **manually**, and the post link is entered into the system.

After audit, creator information is queried before each post; a "cannot post right now" response is not an error (the 24-hour posting limit is shared across all applications the creator uses), and the user is told to try again later. Since there is no scheduled post parameter, scheduling is done server-side.

## Messaging

There is no API that allows businesses to initiate messages to users. Business Messaging can only be initiated by the user, is through a third-party provider, and is not supported on US/UAE/Switzerland/UK accounts. Creator communication is done via email, manual message, or through TikTok One if access is available. There is no TikTok DM button in the panel for this reason.

## Account linking and follower data

The influencer clicks "Connect with TikTok" from their own panel (Login Kit). After linking, follower, video, and like counts are automatically updated. Cover image links are temporary, so they are not stored.

## Missing metrics

Watch time, completion rate, and follower demographics are **not available** in the public API; they are collected via screenshots uploaded by the creator or media kit.

Features dependent on TikTok One / Creator Marketplace API are **intentionally** not included (invite-only access).
