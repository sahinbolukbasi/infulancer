## What is pulled

With the `channels` endpoint (`forHandle=@channel`), subscriber count, video count, and total views. The system calculates average views per video and displays it on the profile.

## Quota

Default project quota is **10,000 units per day**; a `channels.list` call costs 1 unit, `search.list` costs 100 units. Since sync only uses `channels`, hundreds of channels fit comfortably within the daily quota. If quota is exceeded, the error is logged to the account and retried the next day.

## What cannot be pulled

Audience demographics, watch time, and revenue data can only be obtained via **YouTube Analytics API** and only with the channel owner's OAuth approval; this connection does not yet exist. These data are entered from screenshots uploaded by the influencer.
